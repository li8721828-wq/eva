## 一、核心结论摘要

1. **多模型聚合中转已成为国产大模型分发的默认渠道形态**。硅基流动（SiliconFlow）单一价格页即聚合 DeepSeek、智谱（Z-ai）、月之暗面（Kimi）、MiniMax、通义（Qwen）、百度、腾讯混元、字节 Seed、阶跃（Stepfun）、面壁（inclusionAI）、美团 LongCat、BAAI、电信星辰、FunAudioLLM、可灵（Kolors）等 15+ 厂商、覆盖对话/生图/语音/视频多模态模型——这是"OpenAI 兼容 API 网关 + 多模型聚合路由"模式的直接实证。

2. **推理定价已从"单一低价"演进为"分层 + 动态"精细化结构**。同一平台内同时存在：共享池低价、Pro 独占算力溢价、闲时（凌晨 2–8 点）半价、缓存命中约 10% 输入价、长上下文分段加价（如 Qwen3.5 系列 128k 以上加价 2–3 倍）。价格战并未停留在"比谁更便宜"，而是转向"用价格结构引导流量、削峰填谷、提高算力利用率"。

3. **KV/前缀缓存定价成为算力池标配**。硅基流动所有主流模型均单列"缓存价格"，普遍为输入价的 10%（如 DeepSeek-V4-Flash 缓存 ¥0.15–0.30 vs 输入 ¥1.5–3.0；GLM-5.2 缓存 ¥2.0 vs 输入 ¥8.0）。这说明缓存命中率是算力池成本结构的第一杠杆，也是中转平台相对单厂商直连的核心工程差异点。

4. **免费模型是获客入口，Pro/独占算力是变现出口**。价格页上 GLM-Z1-9B、PaddleOCR-VL、Hunyuan-MT-7B、bge 系列、星辰 ASR、Kolors 生图等均免费；同一模型提供"Pro"档（独占/稳定实例，部分溢价），典型"免费引流 → 共享池走量 → Pro 收溢价"的三层漏斗，与海外 Together AI / Fireworks 的商业模式同构。

5. **价格战与推理成本下降对中转模式是"双刃剑"**：一方面毛利被压缩、纯差价型中转商加速出清；另一方面需求价格弹性放大、总 token 量高速增长，有自有算力池 + 推理引擎优化（vLLM/SGLang 类）+ 缓存工程能力的玩家反而受益。行业洗牌方向是"从倒差价走向卖工程能力"。

6. **2026 年模型代际已显著推进**（价格页出现 DeepSeek-V4、GLM-5.x、Kimi-K2.7、Qwen3.6 等），且同一模型存在"厂商直连价"与"平台价"并存（如 DeepSeek-V3.2 与 DeepSeek-V3.2(Pro) 同价），说明平台在部分模型上以平价甚至补贴换取流量，价格竞争仍在继续。

7. **国产算力适配、OpenAI 兼容标准化、边缘/弹性算力**三条主线方向明确，但**本次未能取得可核实的公开证据**（web_search 无结果），详见"未能核实事项"——不构成结论，仅列为待验证假设。

## 二、分维度分析

### 2.1 行业价格战与推理降价潮

**已验证事实（一手页面证据）**：截至 2026-09-03，硅基流动上主流模型输入价已普遍进入"每百万 token 人民币 0.4–12 元"区间，且存在大量免费模型；DeepSeek-V4-Flash 提供 2:00–8:00 闲时半价（输入 ¥1.5 vs ¥3.0，输出 ¥4.5 vs ¥9.0）。这说明"低价 + 动态定价"已是常态而非促销。

**未能核实（一般性推理，非本次证据）**：行业普遍认知中，2024 年 5 月 DeepSeek-V2 以"每百万 token 1 元级"定价引发第一轮降价潮，2025 年初 DeepSeek-R1 发布后各厂商（字节、阿里、百度、智谱等）密集跟进降价，部分模型一年内价格下降 90% 以上。此时间线**未经本次检索证实**，需以官方公告/权威媒体为准。

**趋势判断**：降价潮的传导路径为"模型厂商降价 → 中转平台同步调价 → 差价空间收窄 → 中转商被迫转向算力运营与增值服务"。对中转算力池而言，价格战压缩的是"信息差利润"，而非"工程利润"。

### 2.2 推理成本下降曲线

**已验证事实**：缓存定价（≈10% 输入价）与闲时半价的存在，说明平台已将"算力利用率"和"缓存命中率"显性化为价格机制——这是成本下降的工程来源，而非单纯补贴。

**未能核实**：具体的"推理成本逐年下降百分比"（如"每 token 成本年降 50–90%"类数据）本次无来源可引。此类数据通常出自厂商发布会（如 DeepSeek 技术报告）、SemiAnalysis/Analysis Group 类机构报告，需定向检索。

**推理（标注为推理）**：推理成本下降由四条曲线叠加：① 硬件代际（H100→H200→B200/国产芯片）；② 推理引擎优化（vLLM、SGLang、投机解码、PD 分离、动态批处理）；③ 模型架构（MoE 稀疏激活、MLA 类 KV 压缩、小模型蒸馏）；④ 缓存与调度（前缀缓存、跨请求 KV 复用、闲时填谷）。中转算力池恰好是②③④三者的集成者，因此其单位成本下降通常快于单厂商直连。

### 2.3 国产算力（昇腾、寒武纪等）适配进展

**未能核实**：华为昇腾（Ascend 910B/C）、寒武纪（思元 590/690）在 vLLM/SGLang 等主流推理栈上的适配成熟度、国产卡在中转算力池中的实际占比、以及"国产卡 + 开源引擎"的性价比对比，本次均无公开证据可引用。已知的一般性事实（非本次证据）：vLLM 与 SGLang 官方仓库近年持续增加昇腾/寒武纪后端支持，国内云厂商（华为云、阿里云、百度智能云）均提供国产卡实例——**以上为背景知识，未经核实**。

**趋势判断（推理）**：国产算力适配是 2024–2026 中转算力池最重要的供给侧变量之一：① 政策与供应链安全驱动国产卡进入推理集群；② 国产卡生态（算子库、通信库、推理框架支持）成熟度决定其能否进入"统一调度池"而非仅作隔离资源；③ 若国产卡单位算力成本低于进口卡，将直接拉低中转平台边际成本，加速价格战。此条需后续专项调研补证。

### 2.4 中转算力池模式的增长与洗牌

**已验证事实**：硅基流动的运营形态即为"中转算力池"的典型样本——多厂商模型聚合（中转）+ 共享/Pro 分层算力（池化）+ 缓存与闲时定价（调度）。其价格页同时展示"厂商直连价"与"平台价"，说明平台在部分模型上承担了差价补贴角色。

**未能核实**：OpenRouter、Together AI、DeepInfra、Fireworks AI 等海外平台的 2024–2026 流量/收入/定价数据，以及国内各类商业 API 中转站的规模与洗牌案例，本次无来源可引。

**趋势判断（推理）**：中转算力池的演进路径可归纳为三个阶段：① 纯 API 聚合（倒差价，门槛低、同质化严重）；② 自建算力池 + 推理优化（缓存、批处理、调度，形成成本壁垒）；③ 算力市场/弹性供给（按需租用、闲时竞价、边缘节点）。2024–2026 正处于①→②的洗牌期，纯差价型玩家被压缩，具备自有 GPU 池与工程能力的混合型玩家（如硅基流动、无问芯穹）占优。

### 2.5 OpenAI 兼容 API 生态的标准化影响

**未能核实**：OpenAI 兼容协议（/v1/chat/completions 等）成为事实标准的普及率数据、各平台兼容度差异，本次无来源。

**推理**：OpenAI 兼容 API 是"中转"模式的技术前提——它把"多模型聚合"的成本降到"换一个 base_url + api_key"级别，极大降低用户切换成本，放大了聚合平台的网络效应；但标准化也意味着功能同质化，竞争焦点被迫转向价格、稳定性、缓存收益与生态（工具链、Agent 框架默认支持）。标准化是中转模式增长的"放大器"，也是价格战的"加速器"。

### 2.6 边缘/弹性算力供给趋势

**已验证事实**：硅基流动的闲时半价（2–8 点）与 Pro 独占档并存，说明"弹性/分层算力供给"已进入产品化阶段——平台用价格信号把非实时需求引导到低负载时段，本质是算力池的削峰填谷。

**未能核实**：边缘算力（端侧推理、CDN 边缘节点、手机/PC 闲置算力）在 2024–2026 的实际落地规模与商业模式，本次无来源。

**推理**：弹性算力供给的演进方向：① 时间维度弹性（闲时折扣，已验证）；② 资源维度弹性（共享池 vs 独占实例，已验证）；③ 空间维度弹性（多地域节点就近调度）；④ 所有权维度弹性（自有池 + 租用池 + 市场竞价池混合）。中转算力池的终局形态可能是"算力交易所"：以 API 为界面、以价格信号为调度器、以缓存和批处理为效率杠杆。

## 六、后续可深挖方向

1. **成本结构拆解**：以硅基流动价格页为基准，对比各模型"平台价 vs 厂商直连价"，量化差价与补贴幅度，反推中转平台毛利空间。
2. **缓存经济学**：缓存 10% 定价背后的成本假设（前缀缓存命中率、KV 显存占用、PD/DC 分离架构），可结合 vLLM/SGLang 文档做技术验证。
3. **国产算力专项**：昇腾/寒武纪在主流推理引擎的适配状态、性能对比（吞吐/token/s、每 token 成本），判断国产卡进入统一调度池的时点。
4. **洗牌案例库**：收集 2024–2026 年中转站/聚合平台关停、转型、被并购案例，验证"纯差价模式出清"假设。
5. **弹性定价机制**：闲时折扣、竞价实例、Spot 算力在中转平台的产品化程度，对比海外（如 Modal、RunPod、Together 的按需/竞价模式）。
6. **OpenAI 兼容生态**：统计主流平台兼容端点差异（工具调用、结构化输出、多模态协议扩展），评估标准化红利与同质化风险。
