# 国内大模型 API 中转 / 算力池主要玩家调研

> 调研时间：2026-09-03。方法：web_search + read_web_page 交叉验证，优先官网。

## 一、核心结论摘要

1. **国内玩家分三类定位**：云厂商聚合平台（阿里云百炼、火山引擎方舟、百度千帆、腾讯云 TI）、独立聚合/推理服务商（硅基流动、无问芯穹 Infini-AI）、灰色商业中转站（个人/小团队 OpenAI 兼容 API 代理）。前两类有公开官网与合规主体，第三类本次未能获取可核实来源。
2. **硅基流动是典型的"混合模式"**：既聚合多厂商模型（DeepSeek、GLM、Kimi、Qwen、MiniMax、混元、Seed、BAAI 等），又自研推理引擎与预留实例（独占算力），官网宣称推理延迟最高降低 70%、吞吐提升 3–5 倍，并支持昇腾等国产 GPU 私有化部署。
3. **定价已进入"精细化分时计价"阶段**：硅基流动价格页显示 DeepSeek-V4-Flash 在 2:00–8:00 闲时输入 ¥1.5/M tokens，忙时 ¥3.0/M tokens；输出闲时 ¥4.5、忙时 ¥9.0。缓存命中价低至输入价的 1/10（¥0.15–0.30/M tokens）。算力闲时调度与 KV cache 定价已是公开卖点。
4. **云厂商走"模型 + 平台 + 订阅"路线**：阿里云百炼以 Qwen 自研模型为核心（Qwen3.8-Max 等），推出 Token Plan 订阅（包月最低 39 元起），强调企业级 RAG 与智能体落地；腾讯云 TI 平台则偏"AI 开发平台即服务"，平台本身免费体验、按关联云资源（如 COS）计费。
5. **国产芯片适配是差异化叙事**：硅基流动官网明确列出"基于昇腾算力实现国产化部署突破"（政务场景），但各玩家算力池中国产芯片的实际占比均未在本次可读页面披露，属"未能核实"。
6. **价格战与推理成本下降的传导**：从硅基流动价格页可见多档低价模型（Step-3.5-Flash ¥0.7/M 输入、Qwen3.5-35B-A3B ¥0.4/M 输入、GLM-Z1-9B 免费），推理成本下降已直接反映为聚合平台的零售价下探。
7. **灰色中转站（OpenRouter 类国内镜像、个人中转站）**：本次检索未能获得任何可核实的公开来源（搜索引擎多次返回零结果，相关页面不可读）。其市场现状、差价模式与合规风险只能列为待深挖项，**不能**在本报告中给出结论。

### 2.2 接入的模型生态

**硅基流动（已核实，来源：siliconflow.cn/pricing）**，按厂商分组：
- 对话模型：deepseek-ai（DeepSeek-V4-Flash/V4-Pro/V3.2/V3.1-Terminus 等）、zai-org/THUDM（GLM-5.2、GLM-4.5V、GLM-4-32B 等）、moonshotai（Kimi-K2.7-Code、K2.6）、MiniMaxAI（M2.5）、Qwen（Qwen3.6/3.5 系列，含 MoE 如 397B-A17B、122B-A10B、35B-A3B）、stepfun-ai（Step-3.5-Flash）、inclusionAI（Ling-flash/mini）、tencent hunyuan（Hunyuan-MT-7B、A13B）、ByteDance-Seed（Seed-OSS-36B）、meituan-longcat（LongCat-2.0）、BAAI（bge 系列 embedding/reranker，部分免费）。
- 生图：Tongyi-MAI Z-Image、Baidu ERNIE-Image、Qwen-Image、Kwai Kolors（免费）。
- 语音：XingChen ASR/GSR（免费）、Qwen3-ASR、FunAudioLLM CosyVoice2、MOSS-TTSD、SenseVoiceSmall。
- 视频：Wan-AI Wan2.2-I2V/T2V-A14B（¥2/个）。

**阿里云百炼（已核实，来源：aliyun.com/product/bailian）**：千问系列（Qwen3.8-Max、Qwen3.8-Flash 百万上下文）、千问图片生成、千问视觉理解、万相 Wan3.0 视频生成；配套企业级多模态 RAG 知识库。

**腾讯云 TI（已核实，来源：cloud.tencent.com/product/ti）**：不主打模型清单，主打平台能力（训练/应用/OCR 细分），框架支持 TensorFlow、Torch、PySpark。

### 2.3 定价与计费方式

**硅基流动（已核实）**：
- 按 token 计费，输入/输出/缓存三档价格；部分模型按上下文长度分档（如 GLM-5.1 32k 上下、Qwen3.5 128k 上下）。
- 分时段计价：DeepSeek-V4-Flash 闲时（2–8 点）约为忙时半价。
- "Pro"档位：同模型有 Pro 变体（如 DeepSeek-V3.2 Pro、GLM-5.1 Pro），价格更高，通常对应更高稳定性/独占资源。
- 免费模型：GLM-Z1-9B-0414、Hunyuan-MT-7B、XingChen ASR 系列、SenseVoiceSmall、Kolors、bge 系列等。
- 预留实例：面向企业核心推理的独占算力方案（官网产品页提及，具体价格未披露）。

**阿里云百炼（已核实）**：Token Plan 订阅制（包月最低 39 元起）、后付费按量计费（Wan3.0 限时 7 折）、新人千万 tokens 免费试用。

**腾讯云 TI（已核实）**：平台免费体验，按关联云服务（如 COS 存储）计费。

**火山方舟 / 百度千帆 / 无问芯穹 / 中转站**：未能核实。

### 2.5 技术特色

- **硅基流动（已核实）**：自研全栈推理引擎，跨芯片多模型适配；推理延迟最高降低 70%、吞吐提升 3–5 倍；预留实例（独占算力、精度保障）；私有化部署方案。
