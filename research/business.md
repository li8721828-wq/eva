## 一、商业模式分类

基于已读取的公开来源，可将该领域玩家按商业模式分为以下几类：

### 1. 纯中转 / 差价聚合（API 聚合网关）
**代表：OpenRouter**
- OpenRouter 官方 FAQ 明确说明其模式："OpenRouter 提供统一 API 接入市场上所有主流 LLM 模型，允许用户在一个地方聚合账单"，且 **"OpenRouter 透传（passes through）底层提供商的定价"**，不额外加价，同时聚合各提供商的可用性（uptime pooling），通过统一 API 和故障回退获得更高可用性。
- 收入来源（官方文档可佐证的部分）：用户预充值信用额度的资金沉淀、订阅/套餐、以及面向开发者的增值服务（如 BYOK 自带密钥接入、Batch API 批量接口、MCP 服务、日志与可观测性集成等，见 openrouter.ai/docs/llms.txt 文档索引）。
- 特点：**轻资产、无 GPU 采购成本**，本质是"流量 + 计费 + 路由"生意；加价空间受"透传定价"承诺约束，毛利来自服务费/订阅/资金沉淀而非 token 差价。

### 2. 自有算力池 + 按量计费（推理云 / Serverless Inference）
**代表：Together AI、DeepInfra、Fireworks AI（海外）；硅基流动、无问芯穹等（国内，未核实）**
- Together AI 定价页显示其按每百万 token 计价（serverless inference），并提供 **Batch API 折扣价**（如 Qwen3.5-122B-A10B：标准价 $6.00 输入 / $15.00 输出，Batch 价 $7.50→$6.00 输入、$10.00 输出，折扣约 20%–33%）。
- DeepInfra（据 Spheron 2026 年行业分析文章）采用 **Flex 0.8x / Standard 1x / Priority 1.5x 三级费率**，平台 token 单价跨度约 140 倍（从 Llama 3.1 8B 的 $0.02/百万输入 token 到 Kimi-K3 的 $2.85/百万输入 token）；同时直接售卖 GPU 小时租赁（A100 约 $0.89/小时 至 B300 约 $4.89/小时）。
- 特点：**重资产、自持 GPU 集群**，毛利 = token 售价 −（GPU 成本 + 推理优化 + 运维）；通过推理引擎优化和缓存降低单位成本来放大毛利。

### 3. 订阅制（固定月费换 token 额度）
- 未在本次成功读取的页面中获得直接证据。OpenRouter 有充值/信用额度体系；各平台普遍存在"按量 + 套餐"混合计费，但**具体订阅档位与价格未能核实**。

### 4. 算力分成 / GPU 算力市场
- DeepInfra 同时提供 GPU 小时租赁（见上），Modal、RunPod 等以容器化 GPU 算力市场为主（**本次未能读取其定价页，未核实**）。
- 该模式毛利结构简单：GPU 小时价 − 硬件折旧/电力/机房，与 token 计价解耦。

### 5. 企业级定制 / 私有化部署
- 面向合规与数据不出域需求（Spheron 文章提及企业因合规要求 prompt 与输出不能离开自控基础设施而选择专用部署/专用 GPU 租赁）。
- 通常按项目/年费计价，毛利高于标准 API，但**具体报价未公开、未核实**。

### 6. 混合模式（主流趋势）
- 头部玩家普遍"自有算力池 + 聚合第三方模型 + 增值服务"混合：既吃 token 差价（自有算力），又吃聚合流量（第三方模型），再叠加 Batch、微调、专用实例等高毛利服务。

## 二、成本结构拆解

> 以下"已验证"项来自本次成功读取的网页；"推断"项为基于已验证数据的合理分析，明确标注。

### 1. GPU 采购 / 租赁成本（最大头，已验证部分）
- 已验证：DeepInfra 生态内 GPU 小时租赁价 **A100 ≈ $0.89/hr，B300 ≈ $4.89/hr**（Spheron 2026 分析文章）。
- 推断：对自有算力池玩家，GPU 成本通常占推理总成本的 60%–80%；token 单价与 GPU 小时价的比值（即"每 GPU 小时能产出多少 token"）决定盈亏平衡点，而这取决于推理引擎吞吐量。

### 2. 推理引擎优化带来的成本差异（推断，方向有公开佐证）
- vLLM / SGLang / TensorRT-LLM 等引擎通过连续批处理（continuous batching）、PagedAttention、算子融合提升吞吐（tokens/sec/GPU）。
- 推断：同等硬件下，优化良好的引擎吞吐可提升数倍，直接以相同比例压低单位 token 成本——这是"同一张 H100 上不同厂商 token 单价可差数倍"的根本原因，也是自有算力池玩家毛利率差异的主要来源。
- 佐证：DeepInfra 平台 token 单价跨度约 140 倍（$0.02 → $2.85/百万输入 token），除模型大小差异外，也反映引擎与调度效率差异（Spheron 文章）。

### 3. 缓存命中率对边际成本的影响（已验证定价信号）
- 已验证：国内某模型 API 市场（会话早期读取的定价表，URL 未保留在可见记录中，**来源链接未能核实**）显示 DeepSeek-V4-Flash 缓存价 ¥0.15–0.30/百万 token，仅为输入价 ¥1.50–3.00 的 **约 10%**；DeepSeek-V4-Pro 缓存价 ¥1.00 vs 输入价 ¥12.00（约 8%）。
- 推断：前缀/KV 缓存命中时跳过预填充（prefill）计算，边际成本接近纯解码成本；缓存命中率越高，实际平均成本越低。聚合网关因多租户共享前缀（系统提示、few-shot 模板）天然有更高缓存命中率，这是**中转/聚合模式相对单租户自建的一个结构性成本优势**。

### 4. 带宽与运维成本（推断）
- 带宽：对高吞吐文本/多模态流式输出，出口带宽成本不可忽略，但通常显著低于 GPU 成本；国内厂商常以"带宽包月"方式摊薄。
- 运维：集群调度、弹性伸缩、故障回退、限流降级、计量计费系统的人力与基础设施成本；纯中转模式此部分占比更高（无 GPU 但需高可用路由与账务系统）。

### 5. API 中转的加价空间（已验证 + 推断）
- 已验证：OpenRouter 官方承诺透传底层定价（pass-through），即**纯中转的加价空间受公开承诺约束**，其盈利依赖信用额度资金沉淀、订阅与增值服务，而非 token 差价。
- 推断：非公开承诺的中转站（尤其国内大量商业 API 中转）通常以"官方价 × 折扣"或"充值返利"形式获客，实际加价空间来自：上游批发价（大客户协议价）与零售价之差、缓存命中带来的成本节约、以及汇率/结算时差。**该部分无公开数据，未能核实。**

## 四、毛利率估算（推断，未核实）

> 以下为基于已验证数据的数量级推断，**无任何公开财报或访谈数据支撑，仅供方向参考**。

- **纯中转聚合（OpenRouter 模式）**：无 GPU 成本，毛利 ≈ 服务费/订阅收入 − 支付通道与账务成本。若按 token 差价计，受"透传"承诺约束趋近 0；实际盈利依赖资金沉淀与增值服务。毛利率数字**未公开**。
- **自有算力池（DeepInfra/Together 模式）**：以 A100 $0.89/hr 为例，若单卡吞吐达到 1,000–3,000 tokens/s（优化引擎水平，推断值），每小时产出约 3.6M–10.8M tokens，对应 Llama 8B 级别 $0.02–0.05/1M 的售价，**单卡小时收入约 $0.07–0.5，与 $0.89 的硬件成本相比，低价档模型在裸 GPU 成本上即可能亏损**——这解释了为何低价模型必须靠批量、缓存与高利用率摊薄成本，也解释了为何厂商倾向主推高单价大模型。**该计算为推断，吞吐假设未经核实。**
- 毛利率排序（推断）：企业定制/私有化 > 高单价大模型 API > 低价小模型 API（可能为负）> GPU 小时租赁（接近硬件成本加成）。
