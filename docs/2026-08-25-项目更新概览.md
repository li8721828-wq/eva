# Eva 项目更新概览

日期：2026-08-25

## 本次目标

本次更新围绕两个问题展开：让长任务与普通对话更清晰、更稳定；减少不必要的上下文与界面噪声。

## 对话与任务体验

- 执行中的消息持续显示智能体名称和统一的“正在执行”状态，避免执行阶段只显示图标或重复的过程卡片。
- 工具调用历史默认收起并合并为一条可展开的执行记录，避免一次工具调用生成一条空白助手消息。
- 执行进度会保存在最终回答中；任务中断或失败后，已经显示的过程信息不会消失。
- 新的用户输入、模型开始回复和流式输出更新时，聊天视图会自动定位到底部，减少手动滚动。
- 普通命令默认在后台受控终端执行，不再自动打开右侧终端。只有 SSH、数据库、远程电脑等需要用户观察或交互的会话才显式打开终端。
- 全局对话不再继承项目工作区和项目索引。只有已绑定工作区的对话才能使用项目索引和代码视图。

## 连接与工具调用稳定性

- 对连接关闭、网关中断等错误保留了可追踪的请求诊断信息，方便区分模型服务问题与本地执行问题。
- 修复了部分 OpenAI 兼容网关把工具调用输出为 XML 文本的问题。完整且合法的旧式调用会转换为当前结构化工具调用；内部标记不会再作为回答展示。
- 旧名称 `run_command` 兼容映射为当前的 `execute_command`，但仅在该工具已分配给智能体、参数符合工具定义且整段输出完全为合法工具调用时生效。
- Windows 路径支持 `~`、`~/...` 与 `~\\...` 作为用户主目录的简写，降低跨 Shell 路径错误。
- 运行失败会在受限的高置信度规则范围内沉淀为共享环境规则，例如 Windows PowerShell 环境变量写法；不会把原始报错或任意模型文本直接加入提示词。

## 上下文与 Token 控制

- 智能体详情页新增静态提示词 Token 估算，分别显示专属系统提示词、Eva 平台规则、其他配置、工具说明和工具 Schema 的占比。
- Token 分项可以点击查看；可编辑项在对应详情中保存后立即用于后续请求。只读规则保留为查看，不伪装成可修改内容。
- 共享运行环境规则并入系统提示词构成，适用于全部智能体，不再作为分裂的独立配置入口。
- 工具采用渐进式加载：首轮只提供完成当前请求所需的最小工具集合，拿到工具结果后再按步骤补充后续工具，减少每次请求重复携带的大量 Schema。
- 工具结果、历史消息和工具定义会在每次模型调用前按上下文预算裁剪，优先保留当前请求、最近工具结果和必要系统规则。

## 验证状态

- 单元测试覆盖了工具流、流式文本重置、工具历史合并、上下文构建、Windows 路径处理、渐进式工具加载和旧式 XML 工具调用兼容。
- 本次针对 Provider 的测试已通过：18 项通过。
- 生产构建已通过：`npm run build`。

## 使用建议

- 需要查看本机文件或磁盘时，直接描述目标即可；常规读取会在后台运行并把结果显示在对话中。
- 当模型返回网络错误时，可重试该次请求；若持续出现，则根据错误横幅中的提供商、模型和地址检查网关状态。
- 在智能体配置中优先移除不需要的工具，Token 估算会帮助识别占比最高的工具 Schema。
