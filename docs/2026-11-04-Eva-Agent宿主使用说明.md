# Eva Agent 宿主使用说明

更新日期：2026-11-04。本说明接续 11 月 3 日的原生执行后端改造。

## 定位

Eva 提供统一的桌面画板、模型连接、权限审批和能力插件。所选 Agent 提供执行循环、原生上下文及工具；聊天过程和任务区按该 Agent 的真实公开事件展示。配色、字体、对齐、侧栏和消息操作继续使用 Eva 的界面。

这次补齐了此前会造成差异的几条路径：每轮重建原生上下文、收齐模型响应后才发布原生流、把原生过程压缩成 Eva 进度摘要、强制串行工具，以及缺少 Harness 的原生目标续跑与重试插件。

## 选择与使用

1. 重启本次代码构建的 Eva，进入「设置 → 偏好与模型 → 通用 → 执行引擎」。
2. 选择 Pi Agent 或 DeepSeek Harness，Node 路径可填写 `D:\node\node.exe`，需要 Node.js ≥22.19.0。
3. 保存后从下一次运行生效。模型连接和工具授权仍在 Eva 配置。
4. 原生运行请求上限默认 1000 次，单次输出上限默认 16384 Token。后者还受上下文窗口和 SDK 单次请求限制；应按所用模型实际支持的输出量配置。达到安全上限会报告未确认完成，不会伪装成功。

原生模式不再采用 Eva 智能体的普通循环轮数限制；内部插件子任务明确提供的运行上限仍会生效。过程显示选项不会再把模型慢思考设置隐式关闭。

权限菜单中的「完全访问」同时授权本地全部磁盘和已启用工具免审批，覆盖文件写入、终端命令、浏览器、MCP 和程序化技能等工具类别。Eva、Pi、Harness 及本地 Goal/团队子任务遵守同一会话授权，无需另外关闭全局工具审批。既有 `full-access` 会话下次运行也使用该语义。

切回「仅工作区」或「授权文件夹」后恢复「设置 → 扩展与连接 → 技能与服务 → 工具审批」的全局策略，不会修改其他会话或记住额外的免审批类别。沙箱、只读规划模式、未启用工具、精确文件限制和取消仍有效；完全访问不等于启用所有工具。远程请求继续使用其审批规则。

权限按下一次运行取快照，已经展示的卡片仍需作出决定；当前轮可在卡片上选择「本会话内都允许」对应的操作类别。要加载这次权限语义变更，需要重启本次构建的 Eva。

## 可见行为

### 模型思考档位

输入框的模型选择旁新增思考档位菜单，按连接与模型分别保存，下次运行生效。切换模型再切回会恢复该模型的选择，不修改正在执行的请求。模型、连接和档位通过同一次配置写入保存；保存失败保留原选择。

- 「模型默认」不发送强制思考参数，使用接口默认行为；明确的思考选择独立于“过程显示”和旧思考显示开关。
- DeepSeek 的已知接口提供关闭、低、高、最高；可用档位优先采用连接返回的模型元数据。
- OpenAI 兼容接口使用已确认的 effort 档位；Anthropic 的自适应模式使用 effort，旧版模型显示思考预算档位，预算受单次输出 Token 上限约束。未知能力不统一补出同一组档位。
- Eva、Pi、Harness 和使用相同连接的子任务都读取保存的选择。更高档位通常需要更多时间与 Token，不代表工具结果已通过验收；本功能不增加模型私有推理的展示。

若第三方网关拒绝明确选择的档位，将报告错误，不能静默删除参数后假装该档位生效。模型连接仍需使用该接口实际支持的传输协议。

### 原生执行展示

| 内容 | Pi Agent | DeepSeek Harness |
| --- | --- | --- |
| 执行过程 | SDK 消息边界、原生工具更新和原始输出 | SDK 助手流、回合/步骤、工具和会话事件 |
| 工具显示 | 保留原生工具名、参数和格式化反馈 | 使用工具自己的 `presentCall` / `presentResult` 展示定义，支持读取行号、编辑前后内容和终端退出码 |
| 原生会话 | Pi SessionManager 文件 | Harness JSONL 日志、原生投影和持久附件 |
| 长历史 | Pi 原生压缩 | Harness 原生压缩；压缩事件可见 |
| 长任务目标 | 保持 Pi 自身循环；Eva Goal 可作为扩展使用 | 提供原生 Goal 和同会话自动续轮，在原生目标仍有效时继续推进 |
| 计划 | 按实际输出呈现，不从旁白推测完成状态 | 原生 `todo_write` 列表及 Goal 状态，聊天和右侧任务区同步展示 |
| 请求恢复 | 保持当前 Pi Agent 核心错误语义 | 原生有限重试策略恢复临时模型连接错误，不重放已经执行的工具操作 |

中间旁白保持完整，按消息和工具的真实次序排列。最终答复单独显示；工具详情保留 SDK 反馈。选择引擎不会把 Eva 插件工具伪装为原生工具，网页、MCP、表格等仍标为「Eva 扩展」。任务区里的旧 Eva 扩展任务也与原生状态分开标识。

Harness 原生 Goal 的创建和更新由框架工具决定，完成状态来自真实 Goal 记录；模型说一句“完成”不等于目标已被完成。原生运行结束也只代表该次运行已收尾。停止任务会取消原生运行；恢复后的目标继续遵守 SDK 的重新激活规则。

## 会话续接与切换

同一会话、工作目录和引擎的后续输入会续接其原生状态，保留已记录的原生工具事务和压缩结果。切到另一个引擎时，使用另一个引擎自己的会话；再切回来会导入这段时间新增的对话作为参考。跨引擎参考不冒充原生执行事件。

删除会话、删除后续消息和重新生成会使关联原生状态失效，防止被删除的工作继续影响下一轮。原生状态存储在 Eva 用户数据目录的 `native-agent-sessions` 中，工程记忆不读取这些运行时记录。

未修改的 Eva 内置角色提示不再默认注入原生后端。自建角色和明确修改过的内置角色仍作为用户指定的附加指令使用；用户业务参考和经授权的项目规则继续可用。

## 还原范围

当前是使用原生 SDK 的宿主集成，前端消费真实事件与展示定义，并保留 Eva 样式。它没有嵌入 Pi 的终端 UI 或 Harness 的整套官方 Web 应用，也没有自动加载它们用户目录下的全部插件、独立凭据和 CLI 配置。原生图片可进入模型上下文，尚未把全部官方附件展示组件移植到 Eva。

对比官方客户端时，需要同时核对 SDK 版本、模型连接、思考设置、输出上限及启用插件。测试使用真实 SDK、文件和命令进程，模型响应受控；真实账号长任务的完成率、耗时和费用仍需实测，不能据单元测试保证体验完全一致。
