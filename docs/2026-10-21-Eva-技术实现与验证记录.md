### 存储与写入约束

- 主线以稳定 UUID 保存到 `<project>/.eva/purposes/<uuid>.json`，独立于本机项目 ID 和会话存储。它与 `PROJECT_MEMORY.md` 所代表的仓库工程记忆分开。
- 存储包含目标基线、里程碑、决策/发现、公开进度、执行元数据、交接和变更历史。写入执行 schema、大小、路径、期望 revision 检查，并使用目录锁和临时文件原子替换。
- 损坏 JSON、合并冲突、未知 schema、越界路径不能按空文档覆盖。编辑草稿保留开始编辑时的 revision，刷新列表不能使旧草稿绕过版本冲突。
- `.gitignore` 仅放行根项目 `.eva/purposes/*.json`；锁、临时文件和其他 `.eva` 运行产物继续忽略。
- 每份文档上限 2 MB；单条执行最多记录 100 个工具元数据和 50 个步骤；模型参考上下文最多 24,000 字符。

### 执行、权限和验收

会话通过专用入口关联同项目主线，普通会话更新不能直接写入 `purposeId`。隐藏子会话沿父关系解析主线；桌面聊天、团队、Goal、App Server 和 QQ 的既有会话入口均接入主线上下文。Goal 保留显式隔离交接，在步骤边界刷新有长度限制的 `purposeContext`。

`record_purpose_progress` 属于 `workspace-write`，受原有审批策略约束，内置 Coding Assistant 默认启用；自定义智能体需配置能力。工具可以记录公开报告、验证位置、阻塞和下一步，或将里程碑标记为进行中/受阻，不能修改目标基线或执行人工验收。

里程碑完成必须填写验证依据；整条主线验收要求全部里程碑完成并填写说明。真实执行终态记录工具名称、结果状态、步骤和代码快照。记录失败不会将已经成功执行的工具操作改成可重试失败。

## 三、交接与代码核对

1. 交接预检拦截运行中、排队、暂停可恢复任务和活动子任务。
2. 保存交接时记录 Git 分支、提交，以及暂存、未暂存和未跟踪内容的指纹；排除主线自身文件。
3. 接手检查区分一致、变化、尚无交接和无法核实。读取失败或不支持的文件不能被当作干净状态。
4. 真正继续前再次检查 revision 和代码指纹，创建使用接手方本地模型配置、`workspace` 权限及空目录授权的新会话。
5. 下一步放入输入草稿，由用户发送；继续操作不自动切分支、运行命令、恢复旧工具或提交代码。

测试覆盖将主线复制到另一个项目目录，在不同本地项目 ID 和全新会话存储中继续工作。交接文件不包含代码补丁、原始聊天、命令参数/输出、私有思维链、个人记忆或本地授权。

代码指纹是记录时点的观测，不证明此前每项检查都对应同一版本，也不能阻止外部编辑器随后修改文件。本机写锁不提供跨机器任务租约。意外退出遗留锁时，需先确认没有写入进程，再按[使用说明](PURPOSES.md)处理。

## 四、AI 起草的请求生命周期

新建输入支持 `planningNotes`；IPC 提供 `purpose.generateDraft` 与 `purpose.cancelDraft`。模型只生成表单草稿，用户保存后才创建主线，规划备注转入主线 notes，不增加文档顶层字段。

- 来源：需求文本、用户明确勾选的同项目会话有限公开文本、已有缓存索引的导航元数据。排除 system/tool/progress、推理内容、附件与个人长期记忆；其他工作树的索引不能作为当前代码证据。
- 输入和输出应用常见凭据模式脱敏。结果必须完整通过结构和长度校验；无效 JSON、截断或工具调用响应整体拒绝应用。
- 同一 renderer 限制一个待处理请求；取消按 owner/requestId 隔离，窗口关闭取消所属请求。
- 超时为 60 秒，同时使用 AbortSignal 与 Promise.race 处理不响应取消的 provider；来源改变、取消和超时后，迟到响应失效。
- 失败保留原表单；撤回恢复填入前字段；生成期间锁定相关保存字段。生成不调用工具、不写入既有主线，不产生验收结果。

测试中的模型是受控模拟 provider。模型输出质量和真实供应商兼容性仍需实际使用验证；缓存元数据不等于源码分析或测试证据。

## 五、工作台与设置实现

### 布局和异步状态

[App.tsx](../src/renderer/App.tsx) 与 [use-app-store.ts](../src/renderer/stores/use-app-store.ts) 增加主线展开状态。`workspaceExpanded` 仅存在于 renderer，不进入配置、会话或主线文件。展开/收回/缩放复用同一工作区组件实例，保留草稿；布局夹取不覆盖用户保存的侧栏宽度和高度。

展开工作区是非模态区域，侧栏仍可导航。Escape 优先收回展开视图，再关闭窄屏抽屉。切换工作页、普通会话、新建会话及交接继续时恢复目标内容和输入框。窄窗口仍按 480px 的聊天主列预算切换抽屉，空任务便签默认高度收至 310px，用户尺寸优先。

项目与当前会话作用域不匹配时，不展示旧会话的执行、需求与用量为新项目资料。执行记录区分读取中、失败和真实空态，支持重试；异步请求序号防止旧作用域结果覆盖当前记录。

### 共享控件、导航和状态表达

- 新增 [Switch.tsx](../src/renderer/components/ui/Switch.tsx)，使用原生 checkbox 配合 switch 语义，支持 label、空格键、disabled、焦点和减少动画偏好。多选与验收确认继续使用 checkbox。
- 设置分为三组，仅在当前设置组件生命周期内保留各组上次页面，不宣称关闭或重启后持久记忆。
- 页头、输入、按钮、侧栏选中态消费主题变量，适配三套主题。内置智能体名称和默认说明只作显示映射，保留用户修改和自定义内容。
- 模型池保存中锁定相关操作，失败提示并保留草稿。QQ 校验项目/智能体实际可用性，保留失效 ID 并要求重选，问题清单支持聚焦字段。
- 成本使用未计价/显式零费用/部分计价的不同表达；供应商分布取当前筛选数据。运行状态不把配置数量当成连通性检查，不把历史错误当成当前故障。
- 延续前期去除整页白框和两条装饰线的结果；成本与长期记忆的认可布局作为参考，不全局移除有意义的分组。
