## 二、0.1.216 Maven 宿主验证

| 阶段 | 执行与产物 |
| --- | --- |
| `/verify-host preflight` | 读取 `coding/host-target.json`，核对固定 Git 提交、目标模块、PATH 中的 Maven 及其使用的 JDK。在隔离副本中离线运行原始提交的 `test-compile`，报告缺失依赖。 |
| `/verify-host` | 复核当前 Java 领域产物，把已验收 Java 文件和可选适配补丁叠加到目标模块，导出新增及修改文件的差异。补丁保存在 `coding/output/host/<补丁 SHA-256>.patch`。 |
| `/verify-host run` | 核对预览、配置、领域产物和差异摘要。在新的隔离副本中重做预检并执行离线 Maven `verify`，读取本次的 Surefire 报告。结果保存在 `coding/output/host/verification.json`。 |

适配补丁的范围为目标模块的 `src/main/java` 和 `src/test/java`，允许新增和修改 Java 文件。验收要求每个指定宿主测试套件及生成验收套件实际执行，且报告中没有失败、错误或跳过。验证状态与领域模块状态分别持久化。生成结果重新放行后，旧补丁需要重新预览。隔离联测确认原项目工作区中的未提交修改得到保留。[宿主验证器](../src/main/services/codegen/maven-host-verification.ts) · [Maven 进程与诊断](../src/main/services/codegen/maven-host-process.ts) · [需求工作区](../src/renderer/components/tasks/TaskWorkspacePanel.tsx)
