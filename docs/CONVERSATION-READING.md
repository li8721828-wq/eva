# 对话阅读规范

Eva、Pi、DeepSeek Harness 共用展示规范，执行调度、原始回复、提示词和工具结果仍属于各自引擎。

## 内容边界

- 前端按现有 Markdown 结构展示，不根据关键词猜测结论、补标题、添加加粗或改写正文。
- 原生公开事件的内容、顺序、消息边界和工具来源保持完整；复制答复返回原始 Markdown。
- 正文里的操作命令属于答案，继续显示。执行记录里的命令、参数、反馈默认收起，展开可查。
- 原答案本身冗长或随意使用强调时，展示层只能统一其样式，不能保证得到简洁、结构化的业务总结。

## 阅读层级

| 元素 | 规则 |
| --- | --- |
| 正文 | 默认 15px，13/14/15/16/17/18/20px 档位与设置标注一致；行高 1.88，阅读宽度最多 70ch |
| 标题 | 一至三级分别为正文的 1.25、1.13、1.04 倍，字重 500，通过留白区分层级 |
| 强调 | 字重 500，沿用柔和阅读文字色；无艺术字、阴影和浮动动画 |
| 分隔线 | 中性色 1px 细线，间距固定 |
| 引用 | 次要文字色与中性左边线，无额外卡片 |
| 列表与表格 | 保留语义与顺序；统一缩进、行距和表头层级，表格可横向滚动 |
| 代码 | 等宽字体，主题背景与文字配色，中性边框；长代码限高滚动，复制保留 |

三个 Markdown 渲染器与流式展示共用以上层级；背景、边线和链接沿用 Eva 主题，正文采用柔和的阅读墨色。文档预览的独立样式不受聊天作用域覆盖。旧版装饰偏好继续保存，当前聊天以统一规范为准。

默认无衬线优先使用本机 HarmonyOS Sans SC 的真实 Regular/Medium 字体，通过本地字体映射处理 Windows 的独立 Medium 字体族；未安装时回退到平台无衬线字体。衬线、等宽及 macOS 字体偏好继续保留。正文采用柔和石墨色/雾白色，关闭合成加粗，不使用模糊或阴影修饰字形。字体文件未随应用分发，其他机器的实际字形会受已安装字体影响。

字号只作用于对话正文，应用根字号保持 14px，避免工作区布局跟随放大。字号标签和正文由 `lib/reading-typography.ts` 提供同一份数值。

## 执行记录

- 按“公开说明 → 连续工具列表 → 公开说明 → 新工具列表”的顺序展示。说明文字始终在列表外，不能把整轮内容包进一个执行记录面板。
- 只合并相邻工具，每组独立折叠；入口显示实际工具/命令调用次数及已有报错、停止后未确认的数量。
- 工具与命令采用无卡片边框的轻量行式展示；行内提供名称和文件/命令摘要，展开保留完整参数、原始反馈、SDK 展示内容与真实来源。
- 不根据工具次数或流结束推断整个任务成功，不把工具报错宣称为最终任务失败。
- 运行中的答复持续显示；折叠不停止事件接收，也不改变执行或授权。
- 每个工具列表独立限高、内部滚动并跟随新增工具；用户向上阅读时停止跟随。说明文字使用正常对话布局。
- 任务侧栏的原生目标与待办保持直接显示，用量与耗时在答复下按需展开。
- 展开与滚动状态只在前端存在，不写入会话、配置或 SDK 日志。

原生内容沿用 SDK 的消息/工具顺序；Eva 的公开汇报与工具依据已有时间戳合并，时间戳相同时保持汇报优先、各流内部原顺序。历史记录没有更细顺序时，不伪造新的执行证据。

实现入口：`chat/MessageBubble.tsx`、`chat/ToolActivityList.tsx`、`chat/ExecutionDetails.tsx`、`chat/NativeAgentView.tsx`、`lib/execution-activity.ts` 与 `styles/conversation-reading.css`。浏览器夹具以受控公开事件验证展示，不代表真实账号任务验收。
