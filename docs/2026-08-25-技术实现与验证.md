# Eva 技术实现与验证记录

日期：2026-08-25

## 1. 工具调用兼容层

### 问题

部分 OpenAI 兼容网关没有通过标准 `tool_calls` 字段返回函数调用，而是把调用以如下文本形式写入流：

```text
<tool_call>
<function=run_command>
<parameter=command>...</parameter>
</function>
</tool_call>
```

此前该文本被视作普通回答，因此不会执行工具，也会暴露内部协议。

### 实现

- 在 `src/main/providers/openai.ts` 增加严格的旧式 XML 解析。
- 解析条件：响应整体只能由完整工具块构成；工具必须在当前请求提供的工具集合中；参数名必须属于该工具的 Schema；必填参数必须齐全；不接受重复参数或空参数。
- 添加受限别名：`run_command` 仅映射到 `execute_command`。
- 流式场景中先正常收集文本，流结束后补发结构化 `tool_calls`。`AgentRunner` 已有 `text_reset` 协议，因此会清除先前乐观渲染的 XML，再展示真实工具活动。
- 非流式 `chatComplete` 同步使用同一兼容解析，保持两种调用路径一致。

该设计不会让普通文字、夹带说明文字的 XML、未知工具或不合法参数变成可执行调用。

## 2. 渐进式工具加载与上下文预算

### 实现

- 新增 `src/main/agent-engine/tool-loading.ts`，根据首轮用户请求选择最小工具集合。
- 在 `AgentRunner` 的每个 ReAct 周期中，根据已完成的工具调用决定下一轮需要的工具，并重新生成系统提示词。
- 调用模型前，`ContextManager` 会对消息、工具输出和工具定义进行预算裁剪。
- 工具调用回合中的暂存文本使用 `text_reset` 清理，最终回答只保留完成工具执行后的结论。

### 效果

简单查询不会携带全部工具 Schema；例如天气查询优先使用搜索工具，目录查询优先使用目录工具。复杂任务再逐步开放读取、编辑、验证等能力。

## 3. 共享运行环境规则

### 实现

- 新增环境规则类型与服务：`src/shared/types/environment-rules.ts`、`src/main/services/environment-profile-service.ts`。
- 配置保存于 `AppConfig.environmentRules`，并由 `ContextManager.buildSystemPrompt` 注入全部智能体的系统提示词。
- 环境规则覆盖操作系统、Shell、路径和工具使用约束，并支持带来源标记的受限学习规则。
- `AgentRunner` 仅在已识别的高置信度失败模式中调用学习逻辑，避免将错误日志、用户数据或模型输出无限写入提示词。
- `FileService` 在校验文件访问权限前展开主目录简写，确保 Windows 和常见 Shell 的路径行为一致。

## 4. Token 估算与配置可见性

### 实现

- 新增 `AgentTokenEstimate` 类型和 `IPC.AGENT_TOKEN_ESTIMATE` 通道。
- `src/main/ipc/agent.ts` 使用实际系统提示词构建逻辑和已分配工具定义估算静态输入 Token。
- `AgentTokenEstimatePanel` 展示总量、各分项占比、每项工具 Schema 的占用和可查看的详情。
- 专属系统提示词和共享运行环境规则位于同一系统提示词编辑工作流中；平台规则、工具说明和 Schema 按其实际可编辑性展示。

估算范围只包含当前智能体的静态配置，不包含会话历史、用户输入、工具结果、图片或动态文件内容。

## 5. 会话、终端与索引边界

- `execute_command` 改为后台受控终端运行并返回输出；`open_terminal` 只用于需要用户观察的交互或外部连接。
- 全局会话没有 `workspaceId` 时，项目索引工具直接返回“未绑定项目工作区”，避免错误使用当前侧栏工作区。
- 文件浏览器以当前会话绑定的工作区为准，防止全局会话展示无关项目目录。
- 工具历史和流式进度在存储及渲染层进行合并，减少聊天记录碎片。

## 7. 后续关注点

- 旧式 XML 是网关兼容兜底，不应替代提供商对标准 OpenAI `tool_calls` 的支持。
- 连接被关闭仍属于提供商、网络链路或网关的运行时故障；本次改动保证工具协议不会因其返回格式差异而泄漏到用户回复中。
- Token 估算是静态配置估算。单次请求的实际输入量仍会随对话历史、搜索结果、文件内容和图片变化。
