# 对话输出与界面体验更新

日期：2026-08-27  
版本：v0.1.131

## 本次目标

将执行过程从冗长的工具流水账，收敛为用户能辨识任务仍在进行的轻量状态；同时把“是否显示过程”放回 Agent 模板的输出配置中，而不是作为聊天页的临时开关。

## Agent 输出配置

- Agent 配置新增 `processOutput`，提供三档：`off`、`compact`、`detailed`。
- 该选项位于设置中的 Agent 模板输出配置，随 Agent 保存并应用于后续任务。
- `off` 不显示中间过程；`compact` 仅保留必要的简要进度；`detailed` 显示可读的过程信息，并在提供商支持时请求慢思考内容。
- 最终回答的 Markdown 格式、样式、字体、颜色、字号、文字效果和渲染器仍独立配置，不与过程输出混在一起。

## 过程信息的保存与呈现

- 流式过程更新不再作为一条条短暂消息替换显示；它们会累积到当前助手消息的 `progressUpdates` 中。
- 最终回答到达前，已展示的过程保持可见；最终回答完成后，过程按 Agent 输出档位保留或隐藏。
- 内部生命周期文本、协议重试文本和纯工具格式文本不会作为用户可读过程显示，避免出现无意义的“正在调整下一步”等重复流水账。
- 发生中断时，独立存留的有效过程消息仍可显示，避免任务失败后用户完全失去已发生的上下文。

## 工具调用展示

- 默认界面不逐条展示繁杂工具调用，工具历史聚合为轻量的执行记录。
- 同类调用支持合并计数，结束后的工具信息不再放在最终回答前方干扰阅读。
- 运行中只显示简洁状态文本，不显示小灯、重复卡片或每一项原始参数；详细调用仅在需要排查时展开。
- 工具状态置于助手当前输出的下方，确保阅读顺序始终是：助手说明或正文、执行状态、最终回答。

## 等待状态视觉

- 状态文案统一为“正在执行 . . .”。
- 文案使用从左至右匀速循环的紫色文字流光，不采用独立的圆点指示器。
- 动画采用线性节奏，避免先慢后快；紫色高光覆盖更宽，保持低对比度而不显得突兀。
- 状态文字使用较柔和的常规字重和 14px 字号，避免出现偶发粗黑文本。
- 标签、正文和状态之间增加垂直留白，使执行中的短消息不再拥挤。

## 对话与输入体验

- 聊天视图持续使用同一助手消息容器承载流式正文、过程与工具状态，避免渲染期间内容闪现后消失。
- 用户消息、助手消息、引用、附件和工具结果保留各自职责，避免工具卡片嵌套在正文卡片中。
- 输入栏的附件、命令和提供商选择逻辑被整理为独立的 renderer 辅助模块，降低主输入组件复杂度。
- 使用量摘要保留为可选信息，工具调用详情不再默认占据结果区域。

## 设置与搜索反馈

- SearXNG 插件设置新增“测试连接”，返回清晰的服务状态、结果数量和不可用引擎数量。
- 本地 Docker 服务状态与连接测试分别呈现：前者说明 Eva 管理的容器是否启动，后者说明当前填写的 endpoint 是否可使用。
- 该反馈用于定位搜索故障来源，不把引擎限流等后端事实伪装成前端显示错误。
