# 运行时工具边界

更新：2026-11-26，应用版本 0.1.235。

选择哪个运行时，模型就使用哪个运行时实际提供的工具。Pi/Harness 不再自动挂载 Eva 工具、MCP 或业务扩展，也不会在原生工具失败时回退到 Eva 执行器。

| 运行时 | 当前工具来源 | 目录与搜索 |
| --- | --- | --- |
| Eva | Eva 自身注册的工具及已启用扩展 | Eva 目录、搜索和命令工具 |
| Pi | Pi SDK 的 `read`、`write`、`edit`、`ls` 及平台终端 | 目录使用 `ls`；搜索通过已启用的 Pi 原生终端完成 |
| DeepSeek Harness | DSH 的 `read`、`read_image`、`write`、`edit`、`pwsh/bash`，以及启用的原生 todo/goal | 当前未装载独立目录/搜索插件，通过已启用的 DSH 原生终端完成 |

表内能力仍受智能体工具权限、模型图片能力、规划模式、精确可写文件范围与沙箱约束。没有启用原生终端时，不额外授予终端能力，也不补入 Eva 搜索工具。SDK 中存在某个插件或工具，不代表 Eva 已安装、启用它；当前没有自动加载框架用户目录中的插件、凭据或 CLI 配置。

Eva 继续提供界面、模型连接、授权审批、日志、项目业务参考及上层任务调度。它们属于宿主服务，不是供原生模型调用的 Eva 工具。需要 Eva 专属模型工具时，切换到 Eva，并开始新的一轮；独立的界面功能和斜杠命令不由本次工具目录调整替换。

旧消息中的 Eva 扩展调用仍按历史事实展示。新一轮模型若沿用旧工具名，SDK 会拒绝未启用调用，界面标记“当前运行时未启用”，不会执行或冒充原生工具。模型仍可能生成无效调用，工具隔离不承诺模型永不出错。

更新后首次使用旧 Pi/Harness 会话时，宿主保留旧 SDK 日志，建立采用独立工具配置的新代次，并把本次传入的全部对话历史导入为参考，而非仅取旧游标之后的增量。聊天上下文原有的历史窗口规则继续有效。不会重放旧工具操作，也不声称恢复旧代次的内部检查点；之后正常续接新代次。源代码更新需重启 Eva，运行中的引擎不会热切换。
