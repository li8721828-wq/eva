# Eva 今日更新说明

日期：2026-09-29

今天主要完成了两项与远程使用和模型连接稳定性相关的更新。

## 一、模型连接支持手动填写模型名

有些 API 中转站不提供模型列表接口，点击 `Fetch Models` 会失败或返回空列表。现在不再要求连接必须支持模型列表。

在“设置 → Models → Add connection”或编辑已有连接时：

1. 填写连接名称、Provider、API Key 和 Base URL。
2. 在 `Model name` 中填写中转站要求的精确模型 ID。
3. `Fetch Models` 是可选的。支持列表接口时，可以继续获取模型并勾选多个模型；不支持时直接保存即可。
4. 点击 `Save`。

手动填写的模型会保存为该连接的默认模型，并加入模型库。之后它可以出现在聊天模型选择、Agent 模型访问和模型池中。

例如中转站要求使用 `deepseek-chat`，就直接填写：

```text
deepseek-chat
```

模型名必须使用中转站实际识别的字符串。Eva 不会在保存时猜测或改写模型名。

## 二、公开执行轨迹更稳定

Eva 现在会把真实运行时中的阶段事件稳定显示出来，例如：

```text
正在判断是否需要调用工具
已收到工具结果，正在判断下一步
正在复核当前进度
正在汇总已验证的结果
```

有工具时，界面会继续显示真实的工具调用和工具结果。完整链路会更接近：

```text
判断是否需要工具 -> 工具调用 -> 工具结果 -> 再判断 -> 汇总
```

桌面端和手机 ACP 远程端使用同一套阶段映射，因此两边显示的公开执行状态保持一致。

## 隐私和显示边界

- 模型原始私有思考不会直接作为公开执行证据展示。
- 公开阶段只来自 Eva 已知的运行时生命周期事件，不是模型临时编造的工具记录。
- 重复阶段会在同一轮中合并，避免界面连续刷屏。
- `processOutput` 设置为 `off` 时，不会新增这些公开阶段备注。
