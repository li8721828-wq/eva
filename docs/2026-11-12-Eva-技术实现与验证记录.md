# Eva 2026-11-12 技术实现与验证记录

**日期** 2026-11-12（北京时间） · **源码版本** 0.1.223

本文记录 0.1.219 至 0.1.223。此次提交还收录了 0.1.212 基线之后尚未提交的前序改动，版本归属以工程变更记录为准。[配套更新成果说明](2026-11-12-Eva-更新成果说明.md) · [工程变更记录](project-memory/CHANGELOG.md)

## 一、一次性文件授权与附件预览

- 桌面 Eva、Pi 和 Harness 对受支持文件工具共用路径预检。审批决定绑定发起会话与窗口，只在当前工具调用的路径检查中生效。远程入口继续使用原授权边界。[工具分发](../src/main/services/tool-dispatcher.ts) · [原生工具策略](../src/main/agent-engine/native-tool-policy.ts) · [审批策略](../src/main/services/tool-approval-policy.ts)
- ZIP 预览由主进程只读生成，限制成员数量、目录大小和解压文本预算。ZIP64、加密 ZIP 以及需要完整读取正文的 RMSD 流程需先解压再添加所需文件。[附件服务](../src/main/services/document-attachment-service.ts)

## 二、项目侧栏与模型配置

- 侧栏项目行移除主线快捷按钮，主线仍由聊天标题栏和任务工作区进入。[侧栏项目列表](../src/renderer/components/sidebar/ConversationList.tsx)
- 模型配置和聊天共用 `supportsImageInput`。显式 `visionEnabled` 按连接和模型保存。刷新列表保留该选择，工具探测保留视觉元数据。默认模型出现在列表时，开关与其余模型一样放在行内。[模型设置](../src/renderer/components/settings/SettingsDialog.tsx) · [共享能力档案](../src/shared/model-capabilities.ts)

## 三、单次输出预算

- OpenAI 兼容模型列表读取可用的 `max_output_tokens` 或 `outputTokenLimit`，Anthropic 模型列表读取 `max_tokens`。只有正安全整数才作为声明上限。模型能力档案分别保存上游 `maxOutputTokens` 和用户 `outputTokenBudget`。工具探测及清除探测结果保留两项，刷新列表保留手动预算。[OpenAI 兼容适配器](../src/main/providers/openai.ts) · [Anthropic 适配器](../src/main/providers/anthropic.ts) · [能力类型](../src/shared/types/provider.ts)
- 模型设置与三个引擎共用预算计算。自动模式沿用引擎默认，手动值覆盖默认。上游上限和上下文空间共同限制请求值。Eva 给输出预留上下文空间，Pi 和 Harness 保留现有的四分之一上下文限制，并尊重 SDK 发起的较小预算。[预算计算](../src/shared/model-capabilities.ts) · [Eva 运行器](../src/main/agent-engine/agent-runner.ts) · [原生运行器](../src/main/agent-engine/native-engine-runner.ts)
